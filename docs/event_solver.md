# Event-resolved power model — 29 October 2026

Implemented event_power_lap.py as a new synthetic reference model. Legacy power_lap.py and its rejected convergence evidence remain unchanged. API integrate_segment(vehicle,state,length_m,exit_cap_m_per_s,action_fraction,reserve_j=0,max_speed_m_per_s=100,sample_spacing_m=None,rtol=1e-9,atol=1e-9,max_step_m=5) returns a PowerState and accounting/event evidence. PowerVehicle and PowerState are imported from the existing power model.

The spatial ODE uses q=v^2, battery energy, time and separate work integrals. In propulsion, dq/ds=2*(P/v-k*q)/m. Electrical battery draw is P_e/(efficiency*v) per unit distance. During braking propulsion is off, friction force is m*b and drag remains active, so dq/ds=-2*b-2*k*q/m. The exact downstream braking envelope is (q_target+m*b/k)*exp(2*k*remaining_distance/m)-m*b/k, with the constant-deceleration limit when k=0. Thus b denotes friction deceleration; drag adds deceleration rather than replacing part of the friction term.

Adaptive scipy solve_ivp integration stops at roots for battery reserve, crossing the braking envelope and reaching the maximum speed. Reserve depletion disables electrical power before integration continues. Crossing the braking envelope commits the remainder of the physical segment to braking, with no later acceleration before its endpoint. At the speed ceiling both base/electrical powers are throttled proportionally to drag power. If reserve depletion leaves insufficient base power for the ceiling, the model resumes power-limited motion and speed falls continuously. States already on the initial braking envelope brake immediately. Infeasible entry speeds are rejected.

Sampling spacing controls dense-output observations only. It does not create controller decisions or change integration steps; output-grid invariance must therefore not be mislabelled as integrator convergence. Accuracy requires separate rtol/atol/max_step refinement, delegated to the numerical validator. Physical control segments are explicit boundaries: a requested fraction is held until each boundary or an automatically handled event. No new speed clipping or averaged depletion approximation is introduced. Reserve projection at its located root removes solver roundoff only.

Limitations: synthetic point mass, assumed parameters, fixed line, no tyre grip/downforce/grade, harvesting, real circuit calibration or verified real electrical labels. Terminal speed is capped rather than constrained to an exact equality. Positive speeds are required; stalls raise an error. Speed ceiling, corner endpoints and control segmentation must be declared identically for all controllers. Large exponent envelopes can be unbounded numerically far from a corner, but become finite near the corner; realistic scenario ranges and validator checks remain necessary. A successful synthetic numerical gate permits a synthetic controller experiment only, not an empirical F1 performance claim.
