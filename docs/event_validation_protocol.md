# Event solver validation protocol — preregistered 28 October 2026

This protocol is written before executing the new event-solver study. Original power-grid-001 and diagnostic failures remain unchanged. The original criterion is evaluated literally and separately: every consecutive absolute elapsed-time difference must be strictly smaller than its predecessor, plus original physical and finest-pair relative criteria. Exactly invariant results can fail the literal strict inequality; such a failure must still be reported, never relabelled as an original-gate pass.

## New event-specific gate
The purpose is numerical invariance of an event-resolved solution under subdivision of an unchanged fixed-policy synthetic path. This is a new criterion, not a revision of historical results. Model: PowerVehicle defaults, initial speed20 m/s and energy450000 J, reserve50000 J, fixed deployment0.6, path800m, cap30 m/s at400m and20 m/s at800m, other node caps100 m/s. Original grids40/20/10/5/2.5m remain exactly present. Additional diagnostics1.25/0.625/0.3125/0.15625m use the same physical locations, control and constraints. No controller optimisation or training occurs.

Predeclared acceptance: across all successful grids, elapsed-time spread <=1e-5 s, terminal-speed spread <=1e-6 m/s and battery-draw spread <=0.01 J. Every grid must preserve reserve within1e-6 J, envelope within1e-6 m/s and reported energy residual within0.01 J. A crash/incomplete grid fails the gate. These are absolute numerical tolerances for this bounded synthetic case, not uncertainty bounds for real telemetry.

Independent gates: (1) a zero-drag/no-base-power finite-energy straight must hit its reserve event then coast, matching analytic constant-power speed/time and battery draw; (2) zero-drag/no-power constant-deceleration braking must match work-energy and time for a feasible finite-distance stop-down; (3) an infeasible braking request must be rejected. Analytic tolerances: speed1e-6 m/s, time1e-6 s, work/energy0.01 J. Tests of the validator itself must distinguish literal strict trend from the new invariance rule and reject a violated physical constraint.

Run manifests must identify source hashes, this protocol hash, grids, vehicle/scenario and output hashes. Failure results remain evidence. Passing grants only the specific event-model numerical gate for small synthetic physical training; it does not establish calibrated F1 fidelity, convergence of DP, final evaluation validity or authentic deployment reconstruction.

## API clarification before execution
The event solver integrates physical segments with an adaptive ODE; requested sample spacing changes output sampling only. Therefore the five original grids and four finer grids test OUTPUT-GRID INVARIANCE, not ODE numerical convergence. Their literal original strict-trend result remains separately reported. The event-specific gate additionally requires integration refinement: rtol/atol1e-6,max_step20m;1e-7/10m;1e-8/5m;1e-9/2m; compared with1e-11/1m reference. Acceptance of the default-equivalent fine1e-9/2m result requires elapsed time within1e-5s, final speed within1e-6m/s and energy draw within0.01J of reference; all runs must pass physical checks. Report every error sequence without requiring monotonicity of adaptive-solver errors. These settings and thresholds are declared before execution. Analytic tests remain independently necessary.
