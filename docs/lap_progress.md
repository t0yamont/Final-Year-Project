# Synthetic lap-control gate — 28 October 2026

Action: added lap.py and five independent tests. This bounded control benchmark exposes Scenario, Segment, LapState, default_scenario(), initial_state(), transition() and run_policy(). It supports four default synthetic straights with specified exit speed caps. All five tests pass.

Method: electrical control is a wheel-force fraction in [0,1], explicitly different from the earlier power-controlled dynamics prototype. Acceleration is constant (base force plus electrical force divided by mass). The model analytically chooses an acceleration distance followed by constant-deceleration braking to satisfy the segment exit cap. If that cap is unreachable, acceleration continues to the segment end. An infeasible incoming speed is rejected rather than clipped. Base propulsion and electrical deployment both turn off during braking. Energy draw is electrical wheel force times acceleration distance divided by discharge efficiency. A monotone bisection reduces force uniformly across the acceleration phase if the battery budget would be exceeded; a terminal reserve is protected.

The analytic switching distance is (v_exit_cap^2-v_entry^2+2*b*length)/(2*(a+b)), restricted to the segment length. Phase durations use 2*distance/(entry_speed+exit_speed). Tests independently check total distance, work-energy balance including friction braking, action influence on travel time, depleted energy behavior and infeasible braking rejection.

Limitations: all values are arbitrary teaching assumptions. No drag, power-speed curve, power cap, traction, tyre model, corner geometry, harvesting, calibrated car, real circuit or periodic lap boundary is represented. Exit speed is an upper bound, not a terminal equality. This model therefore supports synthetic controller software comparisons only. Its lack of drag and force-based actuation mean it must not be described as the previously requested physically calibrated qualifying simulator. Full-power-then-depletion switching is not modelled. No actual qualifying or team deployment conclusion follows.
