# Data-source audit and selected course — 10 November 2026

## Decision

Use **OpenF1 historical telemetry + our validated physics simulator**, with **TracingInsights as an archive fallback** and **independently sourced track geometry where layout checks pass**. Keep FastF1 for existing evidence and useful tooling; do not make completion depend on resolving F1 TV access. The user has explicitly accepted a defensible model-based dissertation. The target is a reproducible F1-inspired reference model informed by public telemetry, not identification of a team's private powertrain.

This audit covers the realistic route categories found through primary provider documentation, supplied papers and bounded local access tests. It is not a guarantee that every private dataset or internet mirror has been discovered. Sources are classified below by actual inspection depth. No paid product was bought, no provider was contacted and no bulk season download was run.

## What was actually verified locally

Run `results/source-access-audit-20261110-002` queried public OpenF1 without credentials. The 2025 session catalogue returned **123 metadata entries across 25 meeting keys**, including testing. This is not a count of usable race sessions or proof that every session's telemetry loads.

These are first eligible access-probe windows, not approved clean laps. There are **1,491 retrieved car records** in total, not 1,491 independent experiments. Required fields checked: date, speed, rpm, gear, throttle, brake and DRS. Dryness, lap validity, pit-in, traffic, alignment to location/context and within-lap physical consistency still require checking. The practice gap exceeds the existing one-second development screen. Do not use these samples as final model evaluation.

The first run used an incorrect encoded lower-bound filter (`date>=` as a query key), causing four HTTP 500 responses. Correcting the key to `date>` resolved these requests; the failed run is retained and is not evidence of provider-wide unavailability. Successful metadata/lap responses were reused from a hash-checked cache. No credentials were read or saved. Raw public responses are cached under ignored `work/source-audit-openf1`; summaries, URL/hash provenance and the reproducible probe script are retained.

The TracingInsights Spain qualifying lap-2 arrays contain 554 samples versus OpenF1's 273 for our lap window. This indicates differing representations/sampling, not extra independent evidence. Its derived acceleration and distance fields must not silently become raw measurements. Do not concatenate the same lap from different providers as separate training examples. Match provider IDs, UTC/lap boundaries and channel semantics first. Its corner distances are described as aligned to session fastest laps, so they are not automatically independent geometry for predictive validation.

Run `source-access-audit-20261110-003` reused all nine successful catalogue/lap/car responses and added five successful Spain qualifying context checks: 20 driver entries, 4 stints for driver 1, 77 weather entries, 28 race-control entries and 279 location samples for the selected window. These counts establish access and schemas, not verified joins or clean-lap eligibility. All 14 requests represented in run003 have HTTP 200 evidence; only five were new network requests in that run.

## Full-project implementation plan

1. **Make OpenF1 usable by the existing pipeline.** Build one cached adapter for laps, car channels, location, drivers, stints, weather and race control. Keep native timestamps, units and provenance; reconcile boolean brake with 0/100 representation. Verify one development lap against existing evidence without requiring exact equality between differently processed providers.
2. **Acquire the eight-weekend 2025 frame in resumable batches.** Retain candidates from dataset_expansion_proposal.md. Audit the reference team first; add two constructors as separate contexts only after ingestion works. All available driver metadata can be retained cheaply. Three teams are a coverage target, not a requirement to fit one shared car. Freeze whole-weekend splits before modelling; Bahrain and now Spain are development. Reserve other weekends for validation/test based on availability and layout, not model results.
3. **Use real and simulated data for distinct jobs.** RQ1 combines synthetic known-label recovery with conditional real motion reconstruction. RQ2 trains/evaluates controllers in the action-responsive reference simulator on a principal circuit. RQ3 compares real qualifying-only versus mixed-session motion fitting with matched-volume controls. RQ4 compares conditioning on observable profiles in identical simulated scenarios; profiles need not be claimed as intrinsic driver traits.
4. **Make the reference model credible enough, then stop expanding scope.** Check energy accounting, numerical refinement, feasible braking, sensible motion and sensitivity to plausible parameters. Compare PPO with refined DP and practical heuristics; use independent seeds and uncertainty. Independent integration/optimisation in MATLAB is useful if affordable; it does not independently validate the physical assumptions.
5. **Judge adequacy by evidence, not a fixed lap quota.** Use whole-lap/session learning curves and blocked evaluation. Stop acquiring when the planned context cells have usable coverage and added groups cease materially changing the selected modelling conclusions within predeclared tolerances. If a question remains unsupported, report its bounded result/limitation explicitly; do not invent labels or keep collecting indefinitely.

The accepted outcome is a reproducible model-based comparison, not a perfect digital twin. The audit selects a feasible data route; it does **not** claim that the final dataset or dissertation experiments are complete.

## Cost and reproducibility

The OpenF1 provider currently documents a free historical tier with 3 requests/s and 30 requests/min; this probe spaces requests by at least 2.1 seconds. Production ingestion should also honour rate-limit responses and use bounded retry/backoff. Do not buy a subscription for archived access already demonstrated here. Save request hashes, raw-source lineage and dataset versions; do not re-fetch data for plotting. Original runs remain unchanged. Numerical plots belong in versioned dissertation folders; this audit's sampling figure is in `figures/dissertation/data-source-audit-v1`.

The audit used provider documentation, small actual samples and existing project evidence. No broad agent fan-out or new model-training campaign was needed. Source-reader outputs are cached in ignored `work/source-review-cache` for continuation.
