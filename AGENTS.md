# Project collaboration contract

Read docs/agent_handoff.md first, then only current status and files required for the next bounded task. The user authorises local training/validation and multi-agent collaboration with explicit ownership. Use the lowest capable available model, new agents with minimal summaries (`fork_turns="none"`), compact results and cached tool evidence. See docs/agent_execution_policy.md; prompt-cache hits are not controllable or measurable through available tools.

The coordinator owns integration and research gates. Use focused specialists for independent work when useful. Preserve measured, assumed, reconstructed and simulated evidence distinctions. Passing synthetic tests does not establish empirical validity. Scope, gates and institutional unknowns are in docs/WORKFLOW.md and docs/PROJECT_STATUS.md.

Run bounded pilots with measured budgets, checkpoints and logs before larger jobs. Generate meaningful dissertation comparisons as300dpi PNG and vectorPDF in versioned figures/dissertation folders, with captions, units, run IDs and hashes. Preserve failures and never change historical acceptance criteria silently. Inspect representative figures.

Reuse saved evidence and scoped transition caches only after verifying changed dependencies. Log commands and compact outcomes under logs/agent_tools. Never publish credentials, authenticated caches or private institutional evidence. Keep original run bytes stable. The user explicitly requested inclusion of research results, checkpoints and plots; ordinary generated-result exclusions do not apply to these selected artifacts.
