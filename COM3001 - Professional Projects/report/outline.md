## Evidence-to-prose convention

Each substantive stage should preserve five elements: purpose and rationale; actions actually performed; outputs and verification evidence; discoveries and alternative explanations; problems, unresolved decisions and the next test. Use past tense only for completed work. Separate sourced facts, assumptions, proposed methods and measured results. Stable identifiers for experiments, runs, figures and decisions allow the eventual report to cite evidence without copying execution transcripts into its main argument.

Record failed attempts and subsequent fixes in the project log, then explain only the technically significant ones in the dissertation. State units, scenario and provenance in every result caption. Do not describe software checks as proof of vehicle fidelity or a generated fixture as observed F1 data.
